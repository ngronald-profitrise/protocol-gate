# Support

Thanks for using Protocol Gate! Here is how to get help.

## Documentation first

Most questions are answered in the docs:

- [README](README.md) — overview & quickstart
- [docs/](docs/index.md) — architecture, principles, ADRs
- [PRD](PRD.md) / [TRD](TRD.md) / [DESIGN](DESIGN.md) — requirements & design
- [proofs/README](proofs/README.md) — running the formal verification

## Questions & discussion

- Open a **GitHub Discussion** for usage questions, design questions, or ideas.
- Search existing [issues](https://github.com/ngronald-profitrise/protocol-gate/issues) before filing a new one.

## Bugs & feature requests

- File a **bug report** or **feature request** using the issue templates.
- For research findings about the security model, use the **research finding** template.

## Security issues

Do **not** file public issues for vulnerabilities — see [SECURITY.md](SECURITY.md).

## Response expectations

This is an open-source project maintained on a best-effort basis. Well-scoped issues with reproductions (ideally a failing test) get the fastest responses.
